## 활용 범위

프로젝트 전 과정(설계, 구현, 테스트, 인프라, 문서화)에서 AI를 활용하였습니다.
모든 커밋에 `Co-Authored-By` 태그를 명시하였습니다.

## 활용 방식

### 의사결정 과정

AI에게 완성된 결과물을 요청하는 방식이 아닌, 기술적 판단이 필요한 지점마다 선택지를 비교하고 직접 검증하는 과정을 거쳤습니다.

- 재고 관리 전략: 비관적 락 / 낙관적 락 / Redis Lua 세 가지를 모두 구현한 뒤, 동시성 벤치마크 결과를 확인하고 선택
- 결제 확장성: if-else로 먼저 동작을 검증한 뒤, Strategy 패턴으로 단계적 리팩토링
- 멱등성 처리: exists + save 분리 방식에서 Race Condition을 확인한 뒤 SETNX로 개선

### 작업 진행 방식

- GitHub Issues(#1~#151)와 PR 기반으로 기능을 분리하여 점진적으로 진행
- AI가 생성한 코드를 리뷰하며 불필요한 복잡도 제거 및 구조 변경을 지시
- 테스트 결과와 실제 동작을 직접 확인한 뒤 머지
